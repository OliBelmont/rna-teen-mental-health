## 📌 Descrição do Projeto

Aplicação de Rede Neural Artificial (MLP - Multilayer Perceptron) para prever sinais de depressão em adolescentes com base em dados de uso de redes sociais, sono, desempenho acadêmico, ansiedade e outros fatores comportamentais.

**Dataset:** Social Media Impact on Teen Mental Health (Kaggle)  
**Registros:** 1.200  
**Variáveis:** 13  
**Variável alvo:** `depression_label` (0 = sem depressão, 1 = com depressão)
